1. Keep the chat history after a reload or reconnect. Right now the chat log exists only in the browser page. Any reload, the 15-minute idle disconnect, or the 60-minute Cloud Run connection cut wipes the whole conversation from the student's screen. The TA still remembers the last 24 turns on the server, so it may refer to "the formula above" when nothing is above. The server already logs every turn per student, so on join it should send back the recent conversation and the client should redraw it. A "My conversations" page that lists past sessions and exports them as Markdown would also let students review TA explanations before exams instead of asking again.

2. Make the TA readable for a math course. The chat bubble cannot render math (open issue E9), so formulas show up as raw `$...$` markup. Because the bubble is so small, the TA is also told to answer in three or four sentences, with no lists and no displayed equations. That works for "when is HW 2 due," but not for "walk me through multi-head attention." Render KaTeX in the chat, the same way the Library reading pages already do. Add an "Open full answer" button that shows a longer reply as a page, with headings, lists and displayed equations, using the Markdown renderer the Library already has.

3. Link TA citations to the exact passage. Each TA answer already carries a source tag (📄 reading title), but the tag is plain text. The TA retrieves specific chunks, so the tag should link to the reading page scrolled to and highlighting the passage the answer came from. An LLM TA is only as trustworthy as students' ability to check it. One click from the answer to the source turns "the TA said so" into "here is where the reading says so," and students end up reading the material instead of just the summary.
